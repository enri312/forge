# FORGE v0.11.0

Esta versión consolida el CAS global y el classpath de dependencias locales, y endurece la configuración, la caché, las descargas y la cadena de suministro del proyecto.

## Novedades

- Repositorio CAS global en `~/.forge/repository/cas`, compartido entre proyectos y deduplicado mediante hardlinks cuando el sistema de archivos lo permite.
- Resolución de classpath para dependencias `path:` y salidas compatibles de proyectos externos.
- Comandos `forge cache status` y `forge cache prune`.
- Dashboard local con métricas reales y eventos de compilación SSE.
- Claves incrementales sensibles a configuración, perfil, plataforma y cambios de dependencias locales.
- Tareas personalizadas con `depends-on`, detección de ciclos y propagación correcta de fallos.

## Seguridad y confiabilidad

- Validación estricta de `forge.toml`, rutas, coordenadas Maven/PyPI y grafos de tareas.
- Restauración de caché remota en staging, con límites y rechazo de traversal, enlaces y entradas no regulares.
- Timeouts, redirecciones limitadas, límites de tamaño y validación de artefactos en descargas Maven, PyPI y JUnit.
- Verificación SHA-256 de Maven/POM cuando Central lo publica, con SHA-1 solo como compatibilidad heredada; JUnit usa un SHA-256 fijado.
- Instaladores que verifican el checksum de la release antes de extraer o instalar.
- CI con pruebas multiplataforma, Clippy estricto, auditorías, SBOM CycloneDX, checksums y atestaciones de procedencia.

## Compatibilidad corregida

Las plantillas Java y Kotlin usan JUnit Jupiter `5.12.0`, compatible con el runner JUnit Platform `1.12.0` incluido por FORGE. La combinación fue verificada creando y probando un proyecto Java real desde la plantilla.

## Descargas

- Linux x86_64
- Windows x86_64
- macOS x86_64
- macOS Apple Silicon (aarch64)

Cada paquete tiene un archivo `.sha256` adyacente. También puedes verificar su procedencia con:

```bash
gh attestation verify <archivo> --repo enri312/forge
```
